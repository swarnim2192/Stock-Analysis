📈 Stock Market Analysis with Real-Time Dashboard and AI Prediction

🚀 Project Overview

This project focuses on real-time stock market analysis, specifically targeting Apple Inc. (AAPL) stock. The application provides:

Real-Time Stock Data Visualization 📊

AI-Based Prediction of whether the stock price will go up or down 🤖
Interactive Dashboard built using Streamlit 🌐

🛠️ Tech Stack
Frontend: Streamlit
Data Fetching: yFinance API
Data Analysis: Pandas, Matplotlib
Machine Learning: Scikit-learn (Logistic Regression)
Languages: Python
Techniques: DP (Data Preprocessing), FE (Feature Engineering), ME (Model Evaluation), RTDS (Real-Time Data Streaming)

⚙️ Features
Real-Time Stock Graph: Displays live price updates every minute
AI Model: Predicts stock price direction using Logistic Regression
Auto-Refresh: Automatically updates data without manual refresh

📦 Installation
pip install yfinance streamlit pandas matplotlib scikit-learn

▶️ Run the Application
streamlit run app.py

🤖 AI Model Details
Features: Open, High, Low, Volume

Target: Price Direction (Up/Down)

Model: Logistic Regression

Evaluation: Real-time predictions based on the latest data

✅ Key Contributions
Integrated real-time stock data visualization
Developed AI-based predictive model for stock price direction
